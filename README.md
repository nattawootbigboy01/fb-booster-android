# FB BOOSTER

แอป Android สำหรับช่วยวางแผนการเติบโตของผู้ติดตาม Facebook อย่างเป็นธรรมชาติ

## ขอบเขตเริ่มต้น
- แดชบอร์ดสถิติ (ใช้ข้อมูลตัวอย่างในรุ่นต้นแบบ)
- เครื่องมือวางแผนคอนเทนต์
- คลังโพสต์และตัวช่วยเขียนแคปชัน
- รายการกลุ่มเป้าหมายที่ผู้ใช้บันทึกเอง
- คิวโพสต์และสถานะการอนุมัติ
- โครงหน้าสำหรับเชื่อมบัญชี Facebook ในอนาคต

## ข้อจำกัด
รุ่นนี้เป็น UI prototype เท่านั้น ยังไม่เชื่อม Facebook Graph API และยังไม่ส่งโพสต์จริง
การเผยแพร่ไปยังกลุ่มจะเพิ่มภายหลังเฉพาะวิธีที่ Meta อนุญาตและบัญชีมีสิทธิ์ใช้งาน
ไม่มีระบบบอตติดตาม/เลิกติดตาม ไม่มีบัญชีปลอม และไม่มีการขอรหัสผ่าน Facebook

## วิธีเปิดโปรเจกต์
1. ติดตั้ง Flutter SDK และ Android SDK
2. รัน `flutter create .` หากยังไม่มีโฟลเดอร์ platform ของ Android
3. รัน `flutter pub get`
4. รัน `flutter run`
